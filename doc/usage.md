# 使用说明

## 连接

1. 关闭占用设备的官网驱动或其他工具。
2. 点击顶部「连接设备」，首次选择 Rainy75 V2 键盘或接收器。
3. 基础信息会自动读取，进入动画管理时再按需读取槽位。

页面不会在刚打开时弹出授权窗口。连接后不用在各 Tab 内重复连接。连接异常时点击顶部「重新连接」；设备拔出后状态自动清空。

USB 可使用全部功能。2.4G 可读取电量和控制灯光；点击「切换 USB」可改连有线键盘。在无线状态下开始烧录，也会引导选择 USB。

## 刷写屏幕固件

也可在「固件烧录」点击「社区主题」浏览。卡片静态封面和 GIF 都按屏幕的 320 × 172 比例展示；选择主题后先核对文件大小、SHA-256 和应用结构，勾选风险确认，再点击「使用并返回烧录」。此时只是选中了固件，还需手动点击「开始烧录」。

GIF 默认静止，点击「播放预览」才播放；模拟预览会明确标注，不等于实机录像。

1. 准备适用于 Rainy75 V2 IPS 彩屏的原始应用 `.bin`。
2. 在「关于」中选择文件，检查名称、大小与 SHA-256。
3. 阅读确认项，勾选后点击「使用所选固件」。这一步不会操作硬件。
4. 回到「固件烧录」，核对「待刷入固件」卡片，再点击「开始烧录」。
5. 按浏览器提示授权升级接口，保持 USB 连接与供电直到结束。

BIN 必须对应 `0x08004000` 的 IPS 应用区域。主控、接收器、ZIP、HEX、带安装程序或整片 Flash 备份不在支持范围。结构检查通过也不代表固件兼容或来源可信。

私有主题只有本地开发服务或 `build:local` 产物可见，公开网站不会读取本机被 Git 忽略的文件。

「清除所选固件」不会擦除硬件，只清空网页里的选择。刷新后也不会保留所选文件。没有选中 BIN 时，烧录按钮不可用；设备信息、灯光和动画管理仍可使用。

## 动画与电量

动画管理只操作四个用户槽位中的资源，保留删除确认；没有上传/恢复资源入口。删除前请自行保留原始素材。

续航以 10000mAh、1kHz、RGB 关闭、平均电流 20–50mA 为假设。满电 200–500 小时只是理论算例，彩屏与休眠功耗尚未校准。
