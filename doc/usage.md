# 使用说明

## 连接

1. 关闭占用设备的官网驱动或其他工具。
2. 点击顶部「连接设备」，首次选择 Rainy75 V2 键盘或接收器。
3. 基础信息会自动读取，进入动画管理时再按需读取槽位。

页面不会在刚打开时弹出授权窗口。连接后不用在各 Tab 内重复连接。连接异常时点击顶部「重新连接」；设备拔出后状态自动清空。

USB 可使用全部功能。2.4G 可读取电量和控制灯光；点击「切换 USB」可改连有线键盘。在无线状态下开始烧录，也会引导选择 USB。

## 更新固件

1. 打开「固件烧录」，选择「键盘彩屏」或「2.4G 接收器」。
2. 彩屏可以使用「屏幕主题」或「从电脑选文件」。接收器需要选择对应的 .bin 文件。确认适用设备后，点击「使用这个主题」或「使用这个文件」。
3. 核对「本次要安装的内容」。用 USB 数据线连接键盘，或将接收器插入电脑，然后点击「开始更新」。如果浏览器要求再次授权，点击「选择设备并继续」。更新完成前保持连接和供电。

主题的封面和 GIF 按 320 × 172 的屏幕比例展示，点击「播放预览」查看动画。选用离线包中的主题时，浏览器会要求选择解压目录中的对应 .bin 文件。网页会检查文件大小、SHA-256 和应用结构。

彩屏固件须为从 `0x08004000` 开始的原始应用 BIN。接收器须使用写入偏移为 `0x2000` 的受支持应用 BIN。可展开「文件适用范围」核对要求，并在「固件详情」里查看 SHA-256。

点击「清除选择」或刷新页面可以移除本次选择。私有主题可通过本地开发服务、`build:local` 或本地离线包使用。

## 动画与电量

动画管理只操作四个用户槽位中的资源，保留删除确认；没有上传/恢复资源入口。删除前请自行保留原始素材。

续航以 10000mAh、1kHz、RGB 关闭、平均电流 20–50mA 为假设。满电 200–500 小时只是理论算例，彩屏与休眠功耗尚未校准。

## 断连与休眠恢复

本页成功连接设备后，会记住当前会话中的连接意图。设备意外断开、已授权设备重新出现、页面从长时间后台返回或检测到休眠后的时钟间隔时，尝试恢复同一设备，并重新读取电量、灯光和当前动画管理页的状态。

- 自动恢复仅调用已授权设备列表，不弹出新的授权窗口；有多个无法区分的同类设备时要求手动选择。
- 每轮恢复最多尝试 5 次；后续设备重新出现或页面唤醒可再次触发。不会持续轮询设备状态。
- 手动“断开”停止自动恢复；重新手动连接后恢复启用。刷新页面后需要再次主动连接。
- 固件烧录接管连接时停止后台恢复，BOOT 授权由烧录流程处理；不自动重试刷写、删除或灯光写入。
- 恢复后会提示刷新状态；设备仍处于系统 USB 故障状态或不在授权列表时，网页不能重置系统驱动，需要用户手动恢复设备。
